# Additional-source review

`weekly_sources` is a historical API scope name for the configured additional sources. It does not require a weekly schedule. The scope has its own collection cursor and may run daily.

Channel/discussion pairs come from the private source registry. The audit checks available thread contents against the collected snapshots and records inaccessible or changing threads explicitly. Private historical source lists and review results are not distributed.

See [source configuration](SOURCES.md) and [architecture](ARCHITECTURE.md).
