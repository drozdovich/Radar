# Radar

Radar превращает сообщения из выбранных Telegram-источников в карточки проектов, контактов и событий. В карточке остаются исходник, точная цитата, объяснение интереса, неизвестные условия и решение человека.

Это рабочий персональный прототип на Python и TypeScript с интерфейсом разбора в Twenty. Разработка ведётся с помощью Codex. Автоматических ответов авторам и откликов нет.

## Посмотреть за минуту

```sh
git clone https://github.com/drozdovich/Radar.git
cd Radar
uv run --locked radar demo
```

Нужны Python 3.12–3.14 и uv. Демонстрация работает без аккаунтов и ключей: два вымышленных сообщения, две карточки из одного дайджеста, сохранение решений при повторной доставке. Результат — `.radar/demo/demo.md`. [Готовый пример](../examples/demo.md).

Решения в демонстрации заранее заданы. Проверяется настоящий код контрактов и повторной доставки; качество AI-отбора и живой интерфейс CRM этот пример не измеряет.

## Что устроено внутри

- Сбор полных текстов и сверка двух проходов, восстановление после прерывания.
- Разбор каждого сообщения с точными цитатами и явным указанием неизвестного.
- Отдельные позиции дайджеста с устойчивыми идентификаторами.
- Очередь Project Inbox в Twenty и решения Approve / Reject / Need info.
- История решений, сохранение исходника и защита от дублей.

[Архитектура](../ARCHITECTURE.md) · [Карта данных](DATA_MAP.md) · [Проверки](DEVELOPMENT.md) · [Следующие шаги](../ROADMAP.md)

Публичная версия не содержит рабочую базу, реальные разметки, профиль владельца, Telegram-сессии и настройки его серверов. Полная установка пока требует настройки: код не выдаётся за готовый облачный сервис. Следующая цель — воспроизводимая установка и проверка всего пути до правильно связанных объектов CRM.
